So funktioniert die Touch-Zuordnung

Wihaister bildet Touch-Gesten von Ihrem Client-Gerät auf Mausaktionen der Workstation ab. So steuern Sie den Remote-Desktop auf natürliche Weise über einen Touchscreen — etwa von einem Tablet oder einem Touch-Laptop aus.

Touch-Eingaben laufen durch denselben verschlüsselten Tunnel wie Tastatur- und Mauseingaben und sind aktiv, sobald die Remote-Desktop-Sitzung läuft.

Häufige Gesten

  • Tippen — ein Mausklick an der getippten Position
  • Ziehen — gedrückt halten und bewegen, wird als Maus-Ziehen weitergeleitet (zum Auswählen von Text, Verschieben von Fenstern und Zeichnen)
  • Scrollen — Wischgesten senden Scroll-Ereignisse

Welche Gesten genau verfügbar sind, hängt von Ihrem Client ab. Die Touch-Bedienung ist darauf ausgelegt, mit der Bildschirmtastatur Ihres Geräts zusammenzuarbeiten.

Touch und Tastatur kombinieren

Zeigt Ihr Gerät eine Bildschirmtastatur an, werden ihre Tastenanschläge wie physische Tastatureingaben an die Workstation weitergeleitet. Sie können Textfelder und Terminals mit Touch bedienen und über die Bildschirmtastatur tippen.
