Früher Zugang

Wihaister ist derzeit über das Early-Access-Programm erhältlich. Installationspakete werden an Early-Access-Mitglieder versendet — falls Sie noch keins erhalten haben, sichern Sie sich frühen Zugang.

Wihaister installieren

Windows

  1. Führen Sie den .exe-Installer aus und folgen Sie dem Einrichtungsassistenten.
  2. Wihaister startet automatisch nach der Installation.
  3. Ein System-Tray-Symbol erscheint, wenn der Tunnel-Dienst läuft.

macOS

  1. Öffnen Sie das .dmg-Image und ziehen Sie Wihaister in den Programme-Ordner.
  2. Starten Sie Wihaister aus dem Programme-Ordner.
  3. Erteilen Sie die Bildschirmaufnahme-Berechtigung (erforderlich für Remote-Desktop).

Erste Verbindung herstellen

  1. Öffnen Sie den Wihaister-Client auf beiden Geräten.
  2. Teilen Sie einen Verbindungscode vom Host-Gerät.
  3. Geben Sie den Code auf dem Client-Gerät ein.
  4. Die Verbindung wird automatisch hergestellt.

Plattform-Verfügbarkeit

  • Windows und macOS sind heute verfügbar.
  • Linux-Unterstützung ist geplant.
  • iOS- und Android-Clients sind in aktiver Entwicklung.

Systemanforderungen

  • Windows: Windows 10 oder neuer
  • macOS: macOS 12 Monterey oder neuer
