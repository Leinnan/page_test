Berechtigungen

Welche Berechtigungen Wihaister auf der Workstation benötigt und wie Sie sie erteilen.

Zuletzt aktualisiert: 16. August 2026

macOS

Wenn Wihaister als Host auf macOS läuft, kann es diese Berechtigungen anfragen:

BerechtigungWofür sie benötigt wirdWas ohne sie nicht funktioniert
BildschirmaufnahmeErfassen des Bildschirms für den Remote-Desktop-StreamRemote-Desktop zeigt einen schwarzen Bildschirm
KameraStreamen von Kameras an der WorkstationDas Kamerabild ist nicht verfügbar
BedienungshilfenWeiterleiten von Tastatur- und MauseingabenEingaben erreichen Anwendungen nicht

Sie werden nur beim ersten Einsatz der jeweiligen Funktion um eine Berechtigung gebeten.

Windows

Unter Windows läuft Wihaister als Dienst mit Tray-Symbol. Streaming und Eingabeweiterleitung benötigen keine besonderen Berechtigungen. Läuft der Tunnel-Dienst nicht, fehlt das Tray-Symbol — starten Sie Wihaister über das Startmenü.

macOS-Berechtigungen erteilen

Berechtigungen können jederzeit erteilt oder widerrufen werden:

  1. Öffnen Sie Systemeinstellungen → Datenschutz & Sicherheit.
  2. Wählen Sie die Kategorie (Bildschirmaufnahme, Kamera oder Bedienungshilfen).
  3. Aktivieren Sie Wihaister.
  4. Starten Sie den Wihaister-Dienst neu, damit die Änderung wirksam wird.

macOS fordert Sie möglicherweise auf, eine App neu zu starten, nachdem Sie ihre Bildschirmaufnahme-Berechtigung geändert haben.

Häufige Fragen

Ich habe die Bildschirmaufnahme erteilt, aber der Bildschirm bleibt schwarz. Starten Sie den Wihaister-Dienst neu — macOS übernimmt die Änderung erst nach einem Neustart der App.

Eine Berechtigung fehlt in der Liste. Führen Sie Wihaister einmal aus — die App erscheint erst in einer Kategorie, nachdem sie die Berechtigung angefordert hat. Fehlt sie weiterhin, installieren Sie die App neu.

Beeinflussen Berechtigungen die Privatsphäre? Berechtigungen werden ausschließlich vom Betriebssystem auf der Workstation geprüft. Alles Erfasste läuft durch Ihren Ende-zu-Ende-verschlüsselten Tunnel; Wihaister speichert nichts.
