Permissions

Which permissions Wihaister needs on the workstation, and how to grant them.

macOS

When Wihaister runs as the host on macOS, it may ask for these permissions:

PermissionWhy it is neededWhat breaks without it
Screen RecordingCapturing the screen to stream the remote desktopRemote desktop shows a black screen
CameraStreaming cameras attached to the workstationThe camera feed is unavailable
AccessibilityForwarding keyboard and mouse inputInput is not delivered to applications

You are only prompted for permissions the first time the corresponding feature is used.

Windows

On Windows, Wihaister runs as a service with a tray icon. Streaming and input forwarding do not require special permissions. If the tunnel service is not running, the tray icon is missing — start Wihaister from the Start menu.

Granting macOS Permissions

Permissions can be granted or revoked at any time:

  1. Open System Settings → Privacy & Security.
  2. Select the permission category (Screen Recording, Camera, or Accessibility).
  3. Enable Wihaister.
  4. Restart the Wihaister service so the change takes effect.

macOS may ask you to restart an app after changing its Screen Recording permission.

Frequently Asked Questions

I granted Screen Recording but the screen is still black. Restart the Wihaister service — macOS only applies the change after the app restarts.

A permission is missing from the list. Run Wihaister once — the app only appears in a category after it has requested that permission. If it is still missing, reinstall the app.

Do permissions affect privacy? Permissions are checked by the operating system on the workstation only. Everything captured is streamed through your end-to-end encrypted tunnel; nothing is stored by Wihaister.
