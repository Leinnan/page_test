You can connect to a workstation from any device running a supported client. Platforms marked “in development” are not yet distributed with the early access builds.

How to Read This Page

“Available” means the feature ships in the current early access builds for at least one platform; the Permissions page lists what each feature needs on the workstation. Features marked “Planned” are on the roadmap but are not part of the current builds — do not expect them to work yet.

This page is updated as the early access programme progresses. The list of supported platforms and features is also mirrored on the Getting Started page.
