So lesen Sie diese Seite

„Verfügbar” bedeutet, dass die Funktion in den aktuellen Early-Access-Builds für mindestens eine Plattform enthalten ist; die Seite Berechtigungen führt auf, was jede Funktion auf der Workstation benötigt. Als „Geplant” markierte Funktionen stehen auf der Roadmap, sind aber noch nicht Teil der aktuellen Builds — erwarten Sie nicht, dass sie bereits funktionieren.

Diese Seite wird im Verlauf des Early-Access-Programms aktualisiert. Die Liste der unterstützten Plattformen und Funktionen findet sich auch auf der Seite Erste Schritte.
