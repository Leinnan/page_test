Uprawnienia

Jakich uprawnień Wihaister potrzebuje na stacji roboczej i jak je przyznać.

macOS

Gdy Wihaister działa jako host w macOS, może poprosić o te uprawnienia:

UprawnieniePo co jest potrzebneCo nie działa bez niego
Nagrywanie ekranuPrzechwytywanie ekranu do strumieniowania zdalnego pulpituZdalny pulpit pokazuje czarny ekran
KameraStrumieniowanie kamer podłączonych do stacji roboczejObraz z kamery jest niedostępny
DostępnośćPrzekazywanie wejścia z klawiatury i myszyWejście nie dociera do aplikacji

O uprawnienie jesteś proszony dopiero przy pierwszym użyciu danej funkcji.

Windows

W systemie Windows Wihaister działa jako usługa z ikoną w zasobniku. Strumieniowanie i przekazywanie wejścia nie wymagają specjalnych uprawnień. Jeśli usługa tunelowania nie działa, brakuje ikony w zasobniku — uruchom Wihaister z menu Start.

Przyznawanie uprawnień w macOS

Uprawnienia można przyznać lub cofnąć w dowolnym momencie:

  1. Otwórz Ustawienia systemowe → Prywatność i bezpieczeństwo.
  2. Wybierz kategorię (Nagrywanie ekranu, Kamera lub Dostępność).
  3. Włącz Wihaister.
  4. Uruchom ponownie usługę Wihaister, aby zmiana zaczęła obowiązywać.

macOS może poprosić o ponowne uruchomienie aplikacji po zmianie jej uprawnienia do nagrywania ekranu.

Częste pytania

Przyznałem nagrywanie ekranu, ale ekran nadal jest czarny. Uruchom ponownie usługę Wihaister — macOS uwzględnia zmianę dopiero po restarcie aplikacji.

Brakuje uprawnienia na liście. Uruchom Wihaister raz — aplikacja pojawia się w kategorii dopiero po tym, jak poprosi o to uprawnienie. Jeśli nadal jej nie ma, zainstaluj aplikację ponownie.

Czy uprawnienia wpływają na prywatność? Uprawnienia są sprawdzane wyłącznie przez system operacyjny na stacji roboczej. Wszystko, co jest przechwytywane, trafia przez Twój szyfrowany od końca do końca tunel; Wihaister niczego nie przechowuje.
