File Transfer

Browse files on your workstation, preview them, and download them to your device.

Last updated: August 16, 2026

Browsing Remote Files

The Files view gives you a window into the file system of the connected workstation. You can:

  • Navigate folders with breadcrumbs, just like a local file manager
  • Jump to common locations (Home, Desktop, Downloads) from the bookmarks menu
  • Switch between list and grid views
  • Sort entries by name, kind, size, or modification date

Folder listings are sent as lightweight metadata, so opening a folder feels instant even on slower connections. Thumbnails for images and other supported files load progressively in the background.

Previewing Files

Select a file and choose Preview to see its contents without downloading it first. Previews are generated on the workstation and sent over the tunnel, so large files never need to travel to your device just so you can peek at them.

Downloading Files

To copy a file to your device:

  1. Open the folder containing the file.
  2. Select the file (or use multi-select for several files at once).
  3. Choose Download from the context menu.
  4. Pick a destination on your device.

Downloads travel over the same end-to-end encrypted QUIC tunnel as the rest of your session.

Managing Files

The Files view also supports basic file management on the workstation:

  • Rename — rename files and folders in place
  • Delete — remove entries, with a confirmation step before anything is deleted
  • New folder — create directories on the workstation
  • Get Info — see size, modification date, permissions, and other details

Transfer Security

File listings, previews, and downloads are all carried inside your encrypted tunnel. Nothing related to your files ever travels in plaintext, and relay servers used for fallback routing only forward encrypted bytes — they cannot read your data.
