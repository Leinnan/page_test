Getting Started

Set up Wihaister and make your first connection.

Early Access

Wihaister is currently available through the early access programme. Installers are sent out to early access members — if you have not received one yet, get early access.

Installing Wihaister

Windows

  1. Run the .exe installer and follow the setup wizard.
  2. Wihaister starts automatically after installation.
  3. A system tray icon appears when the tunnel service is running.

macOS

  1. Open the .dmg disk image and drag Wihaister to your Applications folder.
  2. Launch Wihaister from Applications.
  3. Grant screen recording permissions when prompted (required for remote desktop).

Making Your First Connection

Once installed, you can connect to any machine running Wihaister:

  1. Open the Wihaister client on both machines.
  2. Share a connection code from the host machine.
  3. Enter the code on the client machine.
  4. The connection establishes automatically.

Platform Availability

  • Windows and macOS are available today.
  • Linux support is planned.
  • iOS and Android clients are in active development.

System Requirements

  • Windows: Windows 10 or later
  • macOS: macOS 12 Monterey or later
